# Mahadevan Indus Script Corpus - 417 Signs

## Overview

This document contains the complete catalog of 417 Harappan (Indus Valley) script signs as classified by Iravatham Mahadevan in his seminal work "The Indus Script: Texts, Concordance and Tables" (1977).

## Source References

- **Primary Source**: Mahadevan, Iravatham. "The Indus Script: Texts, Concordance and Tables" (1977)
- **Digital Archive**: [Tamil Virtual University](https://www.tamilvu.org/cores/tmp/mahadevan417.pdf)
- **Supplementary**: Wells Sign List (2006) - [Harappa.com](https://www.harappa.com/sites/default/files/pdf/Wells2006-SignList.pdf)
- **Academic Reference**: Parpola Corpus (1994-2010) - [Harappa.com Script](https://www.harappa.com/script)

## Sign Categories

The 417 signs are organized into the following categories:

| Category | Description | Count |
|----------|-------------|-------|
| Anthropomorphic | Human figures and deities | ~20 |
| Zoomorphic | Animals (fish, bull, elephant, etc.) | ~60 |
| Objects | Tools, vessels, weapons | ~80 |
| Numerals | Numerical strokes and markers | ~15 |
| Geometric | Shapes (circles, squares, triangles) | ~50 |
| Botanical | Plants, trees, flowers | ~30 |
| Architecture | Buildings, gates, walls | ~25 |
| Transport | Boats, carts, vehicles | ~15 |
| Tools | Nets, hooks, ropes | ~20 |
| Body Parts | Hands, feet, eyes | ~25 |
| Celestial | Sun, moon, stars | ~15 |
| Weather | Rain, clouds, wind | ~10 |
| Geography | Mountains, rivers, seas | ~30 |
| Titles | Occupations, ranks | ~15 |
| Compound | Combined signs | ~25 |
| Markers | Terminal and special signs | ~2 |

## Data Files

The complete 417 signs are available in the following formats:

- **CSV**: `harappan_417_signs.csv` - Comma-separated values
- **JSON**: `harappan_417_signs.json` - JavaScript Object Notation
- **MD**: This file (`harappan_417_signs.md`) - Markdown documentation

## Usage

### Loading CSV in Python

```python
import pandas as pd
signs = pd.read_csv('harappan_417_signs.csv')
print(signs.head())
```

### Loading JSON in Python

```python
import json
with open('harappan_417_signs.json', 'r') as f:
    data = json.load(f)
print(f"Total signs: {data['metadata']['total_signs']}")
```

### Loading JSON in JavaScript

```javascript
const fs = require('fs');
const data = JSON.parse(fs.readFileSync('harappan_417_signs.json', 'utf8'));
console.log(`Total signs: ${data.metadata.total_signs}`);
```

## Integration with Universal 0/0 System

This corpus is designed to integrate with the Universal Translation 0/0 system through the mapping files in the `mappings/` directory:

- `mapping_harappan_to_00.csv` - Maps Harappan signs to Universal 0/0 codes
- `mapping_harappan_to_tupi.csv` - Maps Harappan signs to Tupi language
- `mapping_harappan_to_hebrew.csv` - Maps Harappan signs to Hebrew
- `mapping_harappan_to_sanskrit.csv` - Maps Harappan signs to Sanskrit
