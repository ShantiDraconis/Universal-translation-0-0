## Ferramentas Associadas

### Gerador de Cartão Soberano
**Localização**: `/tools/generate_sovereign_card.py`

Ferramenta Python para gerar:
- **QR Code** vinculado ao ORCID
- **Cartão visual** com design Harappan
- **Cartão texto** para terminais

#### Uso Rápido:
```bash
# Instalar dependências
pip install qrcode[pil] Pillow

# Gerar cartões
python tools/generate_sovereign_card.py
```

Saída:
- `output/sovereign_cards/qr_orcid_*.png` - QR Code
- `output/sovereign_cards/card_sovereign_*.png` - Cartão completo
