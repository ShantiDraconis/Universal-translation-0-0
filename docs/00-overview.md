# 00-overview

## Overview of the harappan-00-universal Project

This document provides an overview of the project's goals, methodology, and structure.

### Goals

1. Create a systematic mapping between 417 Harappan signs (Mahadevan corpus) and the 00 Universal Dictionary.
2. Document phonetic, numeric, and symbolic methodologies used.
3. Generate academic reports for journal submissions and archives (Zenodo).

### Methodology

The project uses a combination of:
- Phonetic analysis
- Symbolic pattern matching
- Statistical confidence scoring

### Integration

This repository integrates with the broader 0/0 framework ecosystem.
