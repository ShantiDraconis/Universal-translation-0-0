# 02-dictionary-00-link

## Link to Dictionary 00

### Overview

The 00 Universal Dictionary contains 1000 primordial tokens representing fundamental concepts across human languages.

### Location

The dictionary data is stored in:
- `data/dictionary_00/00_dictionary_1000.csv`

### Token Structure

Each token in the dictionary includes:
- Token identifier
- Phonetic representation
- Semantic meaning
- Language family associations

### Integration with Harappan Signs

The mapping between Harappan signs and Dictionary 00 tokens is generated using:
1. Phonetic similarity algorithms
2. Semantic pattern matching
3. Symbolic correspondence analysis
