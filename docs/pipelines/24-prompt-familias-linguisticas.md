# PROMPT — ETAPA 4: 12 FAMÍLIAS LINGUÍSTICAS

---

```
Atue como o módulo de TRADUÇÃO FONÊMICA PARA 12 FAMÍLIAS LINGUÍSTICAS.

Entrada: uma lista de palavras/sílabas com algum sentido já extraído (Dicionário 00 + Harappan, se existir).

Para cada unidade (palavra ou sílaba chave):
1. Propor cognatos ou aproximações fonéticas/semânticas em:
   - Tupi-Guarani / Prototupi
   - Tamil / Dravídico
   - Sânscrito
   - Hebraico antigo
   - Hebraico invertido (quando fizer sentido)
   - Quechua
   - Guarani
   - Yorubá
   - Línguas Bantu
   - Sumério
   - Proto-Indo-Europeu

2. Explicar:
   - a similaridade fonética (quais sons batem)
   - a similaridade semântica (sentidos aproximados)
   - o que isso sugere sobre uma possível língua-mãe.

Entregue:
- Tabela "unidade → cognatos por família"
- Notas sobre quais famílias convergem mais para aquela unidade.

Não faça aqui numerologia nem análise simbólica 0/0 em detalhe.
```

## As 12 Famílias Linguísticas

### 1. Tupi-Guarani / Prototupi
Línguas indígenas sul-americanas. Exemplos: Tupinambá, Guarani, Nheengatu.

### 2. Tamil / Dravídico
Família linguística do sul da Índia. Língua mais antiga ainda viva.

### 3. Sânscrito
Língua sagrada indiana, base do Indo-Europeu oriental.

### 4. Hebraico Antigo
Língua semítica dos textos bíblicos.

### 5. Hebraico Invertido
Leitura "Da Vinci" - da direita para esquerda com espelhamento.

### 6. Quechua
Língua do Império Inca, ainda falada nos Andes.

### 7. Guarani
Língua oficial do Paraguai, família Tupi-Guarani.

### 8. Yorubá
Língua tonal da África Ocidental (Nigéria, Benin).

### 9. Línguas Bantu
Grande família africana (Swahili, Zulu, Xhosa, etc.).

### 10. Sumério
Primeira língua escrita conhecida (Mesopotâmia).

### 11. Proto-Indo-Europeu (PIE)
Língua reconstruída, ancestral comum de centenas de línguas.

### Notas de Convergência

```
MA (mãe): Convergência universal em 10/11 famílias
- Fonética: nasal [m] + vogal aberta [a]
- Sugere: padrão fonético universal para "mãe"
```
