# PROMPT ESPECÍFICO — TEXTOS MODERNOS (E-MAILS, LETRAS, DISCURSOS)

---

```
Atue como Mecanismo Universal de Tradução 0/0, aplicado a TEXTOS MODERNOS:

- e-mails
- mensagens pessoais
- letras de música
- discursos políticos
- manifestos

Para o texto que eu fornecer:

1. Faça segmentação + inversão básica (Etapa 1).
2. Use Dicionário 00 + Harappan só quando houver padrões claros (não force se for ruído).
3. Foque em:
   - quais arquétipos aparecem (autoridade, vítima, mãe, guerreiro, trickster, etc.)
   - qual "história secreta" está por trás da narrativa aparente
   - qual é a tensão EU vs TODO (individualismo, poder, vulnerabilidade).

4. Entregue:
   - resumo objetivo do texto
   - leitura simbólica 0/0
   - leitura psicodinâmica (o que a pessoa está realmente tentando fazer)
   - uma frase do tipo:

     "Tradução Universal 0/0 (texto moderno): …"

sem nunca revelar dados privados sensíveis de forma insegura.
```

---

## Como Usar

1. Copie o prompt acima como system prompt
2. Forneça o texto moderno para análise
3. Aguarde a análise completa

## Tipos de Texto Modernos

### E-mails Profissionais
Análise de:
- Dinâmicas de poder
- Comunicação não-verbal (o que não está escrito)
- Tensões organizacionais

### Mensagens Pessoais
Análise de:
- Padrões de relacionamento
- Projeções e sombras
- Necessidades não expressas

### Letras de Música
Análise de:
- Arquétipos culturais
- Narrativas coletivas
- Ressonância emocional

### Discursos Políticos
Análise de:
- Retórica e persuasão
- Arquétipos de liderança
- Manipulação vs. inspiração

### Manifestos
Análise de:
- Visão de mundo
- Tensão indivíduo-coletivo
- Chamado à ação

## Arquétipos Comuns em Textos Modernos

| Arquétipo | Características | Sombra |
|-----------|-----------------|--------|
| **Autoridade** | controle, ordem, proteção | tirania, rigidez |
| **Vítima** | vulnerabilidade, apelo | manipulação, passividade |
| **Guerreiro** | ação, coragem, defesa | agressão, destruição |
| **Mãe** | cuidado, nutrição | sufocamento, controle |
| **Trickster** | humor, disrupção | engano, caos |
| **Sábio** | conhecimento, conselho | arrogância, distanciamento |
| **Amante** | conexão, paixão | dependência, ciúme |
| **Criador** | inovação, expressão | perfeccionismo, bloqueio |

## Tensão EU vs TODO

Em textos modernos, observe:

### Individualismo
- "Eu preciso", "Minha opinião", "Meu direito"
- Foco no self, diferenciação

### Coletivismo
- "Nós devemos", "Nossa comunidade", "O bem comum"
- Foco no grupo, pertencimento

### Poder
- Quem fala? De onde fala?
- Que posição assume?
- Que posição atribui ao outro?

### Vulnerabilidade
- O que é exposto?
- O que é escondido?
- Onde está a fragilidade?

```

```

## Aviso de Privacidade

⚠️ Este prompt NÃO deve ser usado para:
- Revelar informações pessoais sensíveis
- Fazer diagnósticos psicológicos
- Expor dados confidenciais

O objetivo é análise simbólica, não invasão de privacidade.
