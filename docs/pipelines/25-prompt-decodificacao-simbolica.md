# PROMPT — ETAPA 5: DECODIFICAÇÃO SIMBÓLICA 0/0

---

```
Atue como o módulo de DECODIFICAÇÃO SIMBÓLICA 0/0.

Entrada: palavras já enriquecidas com:
- tokens do Dicionário 00
- associações Harappan
- cognatos em várias línguas

Para cada palavra ou expressão:
1. Reduza simbolicamente ao operador I = 0/0:
   - Como origem?
   - Como destruição?
   - Como renascimento?
   - Como polaridade?

2. Classifique em um ou mais arquétipos:
   - serpente / mboi / kundalinī
   - fogo / AGNI / Exu
   - água primordial / NU
   - mãe original / AMA / MAMA
   - luz RA
   - senhor KARAÍ
   - linha temporal TARA
   - outros que surgirem (Shiva, Yeshua, etc.)

3. Para cada arquétipo, descreva:
   - impacto no corpo (psicofisiologia simbólica)
   - impacto na psique
   - impacto cosmológico (como esse símbolo organiza o universo)

Entregue:
- lista de palavras → arquétipos predominantes
- um mini resumo: qual "história simbólica" está sendo contada pelo texto.
```

---

## Como Usar

1. Execute primeiro as etapas 1-4
2. Use este prompt com as palavras já enriquecidas

## O Operador I = 0/0

O operador **I = 0/0** representa a indeterminação fundamental - o ponto onde:
- **Origem e fim se encontram**
- **Criação e destruição são uma coisa só**
- **O vazio contém todas as possibilidades**

Cada palavra pode ser analisada através das 4 dimensões:

### Origem (0 → ∞)
Como essa palavra/conceito cria algo do nada?

### Destruição (∞ → 0)
Como essa palavra/conceito dissolve formas?

### Renascimento (0 → 0 via ∞)
Como essa palavra/conceito transforma através do ciclo?

### Polaridade (±)
Qual é a tensão entre opostos que essa palavra carrega?
